# 공동훈련센터 진단·컨설팅 아카이브

한국기술교육대학교 일학습병행 공동훈련센터 지원단의 정기 진단·컨설팅 결과를 기관별·항목별로 정리한 페이지입니다.
지원단 홈페이지에서 내려받은 「컨설팅이력목록」 엑셀과 「모니터링 조사표 v9.0」을 기준으로 만들었습니다.

- 현황 요약, 기관별 이력, 점검 매트릭스, 항목별 분석, 조사표 v9.0 화면으로 구성됩니다.
- 왼쪽 아래 **엑셀 불러오기**로 새 「컨설팅이력목록」 엑셀을 열면 브라우저 안에서만 다시 집계합니다(서버로 전송되지 않음).

## 데이터 갱신

이 저장소의 `index.html`은 원본 작업 폴더의 `build.js`로 만듭니다.

```bash
node build.js "컨설팅이력목록_YYYYMMDDhhmmss.xls"
```

만들어진 `pages/index.html`을 이 저장소에 커밋·푸시하면 GitHub Pages에 반영됩니다.
